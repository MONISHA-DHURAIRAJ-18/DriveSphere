# 🚗 DriveSphere

A modern automotive website built using HTML, CSS, JavaScript and Bootstrap.

Users can explore different Tata car models, view detailed specifications, features, images, variants, safety information and calculate monthly EMI.

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Responsive Web Design
- Git
- GitHub

## ✨ Features

- 🚘 Tata car collection
- 📋 Detailed car specifications
- 🛡️ Safety features
- ⚙️ Engine and performance details
- 🎨 Car colors and variants
- 🖼️ Car image galleries
- 💰 EMI calculator
- 📱 Responsive design
- ✨ Premium card-based UI
- 🔗 Individual car detail pages
- 🧭 Easy navigation
